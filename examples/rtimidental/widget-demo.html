🏥 Intégration Externe Démo

Site Web Cabinet Dentaire RTimi Dental

Ce site web simule un site WordPress, Shopify ou Webflow existant sur lequel le **Widget Web GeoCore** est injecté via une simple balise <script>.

Code d'intégration 1-Clic à coller dans votre site :

<!-- GeoCore Universal AI Widget -->
<script
  src="https://cdn.jsdelivr.net/npm/@mormox2/geocore@1.0.0/dist/widget/geocore-widget.js"
  data-api-url="https://api.geocore.rtimi.com"
  data-title="Assistant RTimi Dental"
  data-subtitle="Conseil Clinique & Hygiène"
  data-placeholder="Posez votre question dentaire..."
  data-theme="dark"
  data-primary-color="#0284c7"
  defer>
</script>

👉 Regardez en bas à droite de l'écran : le bouton flottant (FAB) 💬 est actif. Cliquez dessus pour ouvrir l'assistant IA avec garde-fous cliniques.
