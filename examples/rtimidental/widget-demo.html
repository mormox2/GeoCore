🏥 Intégration Externe Démo

Site Web Cabinet Dentaire RTimi Dental

Ce site web simule un site WordPress, Shopify ou Webflow existant sur lequel le Widget Web GeoCore est injecté via une balise <script type="module"> et un élément <geocore-widget>.

Code d'intégration 1-Clic à coller dans votre site :

<!-- GeoCore Universal AI Widget -->
<script type="module"
  src="https://cdn.jsdelivr.net/npm/@mormo_mossaab/geocore/dist/widget/geocore-widget.js"></script>

<geocore-widget
  data-api-url="https://votre-serveur-geocore.example/api"
  data-language="fr"
  data-title="Assistant RTimi Dental"
  data-subtitle="Conseil Clinique & Hygiène"
  data-placeholder="Posez votre question dentaire..."
  data-theme="dark"
  data-primary-color="#0284c7">
</geocore-widget>

Le widget interroge l'endpoint /answer de l'API GeoCore (geocore serve) : chaque réponse est extraite d'un objet de connaissance publié et n'est affichée que si elle passe la vérification d'ancrage. Sinon, le widget indique qu'aucune réponse vérifiée n'a été trouvée.

👉 Pour cette démo, lancez d'abord l'API locale avec npm run serve:rtimidental (http://localhost:3000), puis cliquez sur le bouton 💬 en bas à droite.
