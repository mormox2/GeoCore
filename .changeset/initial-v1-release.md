# GeoCore 1.0.0 — Authoritative AI-Native Knowledge Operating System

- **`@mormox2/geocore`**: 10-stage validation pipeline, knowledge graph, citations, media, static exporter, and in-process APIs.
- **`@mormox2/geocore-cli`**: Extended CLI commands (`init`, `validate`, `export`, `inspect`, `serve`, `vectorize`, `studio`).
- **`@mormox2/geocore-server`**: Standalone HTTP REST server with dynamic OpenAPI 3.1.0 generator and hybrid search.
- **`@mormox2/geocore-db`**: Universal persistence layer with In-Memory and SQLite adapters.
- **`@mormox2/geocore-vector`**: Semantic embeddings, vector store, and Reciprocal Rank Fusion (RRF) hybrid search.
- **`@mormox2/geocore-next`**: Next.js 14+ App Router metadata, route handlers, and UI components.
- **`@mormox2/geocore-ai`**: AI/RAG prompt context builder, semantic chunking, and citation grounding guardrails.
