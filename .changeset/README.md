# Changesets in GeoCore

This directory contains changelog entries and version bumps managed by [Changesets](https://github.com/changesets/changesets).

## Workflow

1. **Add a change entry**:
   ```bash
   npm run change
   ```
2. **Review & Version**:
   ```bash
   npm run version-packages
   ```
3. **Publish to NPM**:
   ```bash
   npm run release
   ```
